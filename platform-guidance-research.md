# Platform Guidance Research

## Official Workday documentation

- Workday describes a candidate choice between reusing a previous application and uploading a new resume or CV. This supports the recommendation to upload a job-specific version for each materially different target role.
- Workday’s Talent Acquisition product describes using AI to glean skills from candidate resumes. This supports clear skill naming and accurate application-profile data, but it does not establish a universal pass score or formatting guarantee.

Sources:

1. https://doc.workday.com/workday-education/en-us/course-manuals/recruiting-for-administrators/prospects-and-candidates.html
2. https://www.workday.com/en-us/products/talent-management/talent-acquisition.html

## Official Greenhouse documentation

- Greenhouse’s MyGreenhouse candidate FAQ notes that the most recently uploaded resume is used by default and can be replaced. This supports replacing the uploaded resume when the candidate changes target roles.
- Greenhouse’s candidate guidance states that a submitted application email cannot be changed afterward. This supports a careful final review of application fields before submission.

Sources:

1. https://support.greenhouse.io/hc/en-us/articles/43418495049499-MyGreenhouse-FAQ-for-Candidates
2. https://my.greenhouse.com/blogs/what-really-happens-after-you-apply-for-a-job

## Practical interpretation for Verity

There is no honest universal Workday or Greenhouse “pass” format. Employer configuration, application questions, and recruiter workflows vary. Verity should therefore emphasize conventional headings, a single-column text-first resume, accurate skills, standard date ranges, job-specific evidence selection, and a separate review of every form field after parsing.
